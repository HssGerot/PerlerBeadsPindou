# PerlerBeadsPindou

拼豆图纸生成器，用于把用户上传的图片或输入的文字转换成带网格、色号和用量统计的拼豆图纸。

## 当前阶段

项目已搭建 Vite + React + TypeScript 骨架，并完成首版工作台界面：

- 图片上传入口与文字输入模式
- 生成设置面板
- 拼豆预览区域
- 色号用量面板
- 下载预览与下载图纸入口
- 图片上传后自动生成拼豆网格
- 支持输入文字生成拼豆网格
- 支持主导色 / 平均色采样
- 支持 48 色 / 全色板匹配
- 支持显示 / 隐藏色号和网格
- 支持下载 PNG 图纸

下载预览、手动格子编辑和用量清单导出会在后续任务中接入。

## 本地开发

```bash
npm install
npm run dev
```

## 验证

```bash
npm test -- --run
npm run build
```

## 设计约束

- 用户图片和生成结果只在浏览器本地处理。
- 首版优先完成“上传图片 -> 生成拼豆图纸 -> 导出 PNG/用量清单”的闭环。
- 复杂手动编辑、专心拼豆模式、多品牌完整色号体系放到后续阶段。
